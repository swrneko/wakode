# wakode

Полностью открытый selfhosted-трекер времени, совместимый с WakaTime по API. Rust-workspace из пяти крейтов, SQLite за репозиторными трейтами, в перспективе — один бинарь со встроенной SPA.

## Запуск

```bash
cargo test --workspace                  # весь набор
cargo build --workspace --all-targets   # обязана быть без предупреждений
cargo run -p wakode -- --config wakode.toml serve
cargo run -p wakode -- --config wakode.toml migrate
```

Остальные подкоманды и команды прогона отдельных наборов — в карте.

## Соглашения

- **Тест обязан быть невакуумным, и это доказывается мутацией.** Доминирующий дефект проекта, находимый ревью за ревью, — тесты и комментарии, утверждающие больше, чем доказывают. Для каждого нового теста вносится мутация, ради которой он написан, проверяется, что тест краснеет, и код возвращается **копированием из резервной копии файла**.
- **Никогда `git checkout` / `git stash` / `git restore` для отката мутации** — так уже терялась несохранённая работа. Только `cp` с заранее сделанного бэкапа.
- **Комментарий не должен обещать больше, чем делает код.** Если абзац объясняет решение, которого в коде нет, — это дефект того же класса, что вакуумный тест.
- `#[expect(..., reason = "...")]`, никогда `#[allow(...)]`.
- Комментарии, докстринги и тексты ошибок — по-русски; имена тестов — английские фразы о поведении.
- `cargo fmt` не гоняется: установленный rustfmt переставляет импорты по стилю edition 2024, репозиторий по нему не чист. Форматирование — по соседнему коду.
- Зависимости — в `[workspace.dependencies]` корневого `Cargo.toml`, в крейт через `.workspace = true`.
- PK/FK — UUIDv7, не v4.
- Никаких упоминаний Claude/AI в коммит-сообщениях.
